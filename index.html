LCO Instruments control surface

Pick an instrument to open its control surface. Each card opens the SPA against that instrument's WebSocket server (port 50001 + PROJECT_ID×100 + 2). Assumes the instrument host is reachable — over the observatory VPN, or via a Cloudflare-Access-fronted tunnel; see security-models.md for either deployment.

ADC

port 52403

Atmospheric Dispersion Compensator — lens A/B encoders, insertion, telescope readback, run/pause.

DCU

port 51703

Diffuser Calibration Unit — FFS and MCal drops with brake interlocks, 8 lamps, quartz level readout.

PFS

port 51603

Planet Finder Spectrograph — Camera window (exposure + mechanics + PMT + focus) and Calibration list.
Advanced — connect to a custom host/port

For remote sessions via Cloudflare Tunnel, use the tunnel hostname (e.g. pfs.instruments.observatory.example.com) as host and leave port empty — the SPA will select wss:// automatically when the host has no port suffix.
