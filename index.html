LCO Instruments control surface

Pick an instrument to open its control surface. Each card opens the SPA against that instrument's WebSocket server (port 50001 + PROJECT_ID×100 + 2). Assumes the instrument host is reachable — over the observatory VPN, or via a Cloudflare-Access-fronted tunnel; see security-models.md for either deployment.

ADC

port 52403

Atmospheric Dispersion Compensator — lens A/B encoders, insertion, telescope readback, run/pause.

DCU

port 51703

Diffuser Calibration Unit — FFS and MCal drops with brake interlocks, 8 lamps, quartz level readout.

PFS

port 51603

Planet Finder Spectrograph — Camera window (exposure + mechanics + PMT + focus) and Calibration list.

PFS quick look

http://127.0.0.1:8766/image/pfs/

Science-frame viewer — imageweb gateway. Streams each readout to the browser; also embedded as the Quick Look tab in the PFS SPA. All instruments: /image/.

gcam03

http://127.0.0.1:8765/guider/gcam03/

Web guider — gcam bridge, test setup. A whole web app under its own path on this hostname, not a WS endpoint. All guiders: /guider/.

gcam41

http://127.0.0.1:8765/guider/gcam41/

Web guider — gcam bridge, test setup. Same bridge process as gcam03; one --guider flag per camera.
Advanced — connect to a custom host/port

Direct (VPN / LAN): host + port. Cloudflare Tunnel: leave port blank and set the ws path (e.g. /adc/ws); host defaults to this page's hostname.
